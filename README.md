# 聊笺 · 微信 AI 工作台

聊笺是 DeepSeek Harness（DSH）的微信阅读工作台。微信流把聊天归档和场景提示词发进 DSH 当前会话。DSH 完成分析后，聊笺收录最终回复和原始聊天记录。

## 安装

安装包为 `dsh-liaojian-0.2.4.tgz`，适用于 DeepSeek Harness `0.2.2-rc.3` 起的 0.2 系列。

**DSH 桌面版**

从本地安装包升级时，先在插件详情里卸载旧版。聊笺的归档数据保存在 DSH 用户目录。

1. 打开 DSH 侧栏的「插件」，点「添加插件」。
2. 在「包名或地址」中粘贴你下载的 `.tgz` 安装包的完整路径，点「安装」，然后点「立即启用」。
3. 从 DSH 侧栏打开「聊笺」。如需更宽的阅读区域，可用 DSH 的「收起侧边栏」按钮。
4. 在 DSH 配置好会话模型。在聊笺的「工作台设置」中填写自己的微信称呼，即可统计「我的发言」。

**DSH Web**

在安装包所在目录运行以下命令。

```sh
dsh plugin --profile web add ./dsh-liaojian-0.2.4.tgz
dsh web
```

## 从微信流发送到会话

1. 在微信里多选要整理的消息，选择「转发 → 合并转发 → 转发到其他应用 → 发给 DeepSeek Harness」。选用微信流中的场景，或直接转发聊天记录。
2. 在 DSH 当前会话的输入框下点 **「存入聊笺」**。按钮会自动加归档标记并发送。场景提示词随消息一起发送。只有 ZIP 时会补上默认的聊天记录分析提示词。
3. 分析完成后，回复下方显示「在聊笺查看」。聊笺按该批微信原话的最新日期收录回复，并渲染 Markdown。已核验的微信流同批 ZIP 会自动归入同一个会话。其他 ZIP 在「所有会话 → 待归类」中选择新建或归入已有会话，可同时标注私聊或群聊。
4. 归入会话后，聊笺用 DSH 默认模型从原始消息提取可追溯到原话的观察，更新日报、侧栏分类和跟进清单。

普通发送的消息保持原有对话流程。已有 `【微信流归档】` 的场景仍可直接发送。聊笺校验 ZIP 内的原生「聊天记录.txt」，并通过 DSH 读取已上传的附件。浏览器和 DSH 主机在不同设备时，请将 ZIP 作为附件上传。

同机收到微信流的 `@路径` 时，Windows 上从当前 DSH 进程的 `%LOCALAPPDATA%` 定位 `WeChatBridge/Inbox/Ready`。微信流使用其他目录时，可在启动 DSH 前设置 `LIAOJIAN_WECHAT_READY_DIR`，指向采用相同投递格式的 `Ready` 目录的绝对路径。聊笺仅在该目录内核对投递清单并读取对应的 ZIP。重新打开已完成的带标记会话时，聊笺会用仍可读取的 ZIP 补归档。 [微信流投递目录格式](https://github.com/freestylefly/WeChatBridge/blob/main/shared/README.md#inbox-共享契约两端必须一致)

### 其他归档入口

- **微信流「沉淀到文件夹」**可选用聊笺「归档记录」里的收件目录。DSH 运行时每 10 秒检查一次。
- **工作台导入**支持点击「导入 ZIP」或拖入一个或多个原始 ZIP。可以指定会话名称和群聊／私聊类型。
- **会话命令** `/liaojian [会话名称]` 可手动导入随命令发送的原始 ZIP。

以上入口会调用 DSH 的默认模型，提炼带原话出处的分类观察。

## 工作台

- **简报**按天和自然周回看。总览可打开微信流分析原文，也会列出工作台生成的精选观察和后续行动。支持导出 Markdown 简报。
- **分类列表**包含「全部观察」「与我有关」「学习」「内容选题」「机会」「我的发言」。可以按群聊、私聊和处理状态筛选，也可以跨日期搜索话题、会话或人物。
- **观察与待办**可以手动新建、编辑、删除，也可以收藏或标为已处理。「跟进清单」默认显示待处理事项，可切换查看已处理事项。从简报打开详情后，点「返回简报」回到原先的阅读位置。
- **所有会话**支持新建会话、编辑名称和类型、导入 ZIP、删除会话。删除会话或归档会移除相关的聊笺 ZIP 副本、原话和依赖这些资料的分析。删除单条观察会保留原始消息。
- **三栏宽度**可以拖动两条分隔线调整。键盘聚焦分隔线后可用左右方向键微调。宽度保存在当前应用或浏览器中。
- **定时汇总**默认使用北京时间。日报在每天 08:30 汇总前一天，周报在周一 09:00 汇总上一自然周。设置中可更改时间、时区、分类和参与分析的会话。关掉 DSH 后，定时任务暂停，重新打开会检查最近一期。历史日期可随时手动汇总。

## 格式和数据

- 接收微信原生合并转发的 ZIP，单文件上限 100 MB，聊天文本上限 8 MB。微信流分批投递的 ZIP 可以逐个导入。解析使用原生 `聊天记录.txt` 中的发送人、时间和正文。
- 图片、视频和其他附件保存在原始 ZIP 中。模型分析聊天文字及其中的附件描述。会话类型缺失时显示「未标注」，可在会话详情中补充。
- 分析结果、消息、标记和简报保存在 `$DSH_HOME/liaojian/workbench.sqlite`，原始 ZIP 在同目录的 `archives` 下。微信流收件目录是 `$DSH_HOME/liaojian/inbox`。
- 聊笺保留 DSH 会话的原回复，可复制或导出 Markdown。分类分析失败时，已解析的原话可在「所有会话」查看，并在「归档记录」点「重新分析」。相同 ZIP 按内容去重，同一会话中重叠的批次按消息去重。
- 升级后，旧版收录且有明确名称或类型的会话归档会补做分类分析。旧版未标注的通用名称和文件名归档会显示在「待归类」，可逐份选择归属。

## 从源码打包

开发命令需要 Node.js 24.9 或更新版本。在项目根目录运行下面的命令。

```sh
npm ci
npm test
node -e "require('node:fs').mkdirSync('dist', { recursive: true })"
npm pack --pack-destination dist
```

安装清单是 `package.json` 和 `cordis.patch.yml`。服务端通过 `session/event` 接收会话轮次，输入框操作和回复入口分别使用 `conversation.input.left` 与 `conversation.chat.turnTail` 插槽。 [DSH 会话文档](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.2-rc.3/docs/subsystems/session.zh.md) · [微信流开源实现](https://github.com/freestylefly/WeChatBridge)
