# 聊笺 · 微信 AI 工作台

聊笺是 DeepSeek Harness（DSH）的阅读工作台插件。把微信中手动选中的消息合并转发，经微信流投递成 ZIP。聊笺调用 DSH 的默认模型提炼待办、商机、学习资料和内容选题，再把观察、简报和对应的原话放进三栏工作台。

## 安装

安装包为 `dsh-liaojian-0.1.0.tgz`。已在 Windows 版 DeepSeek Harness `0.2.2-rc.3` 和同版本 Web 配置上验证安装。

**DSH 桌面版**

1. 打开 DSH 侧栏的「插件」，点「添加插件」。
2. 在「包名或地址」中粘贴安装包的完整文件路径，例如 `D:\下载\dsh-liaojian-0.1.0.tgz`，点「安装」，然后点「立即启用」。
3. 从 DSH 侧栏打开「聊笺」。如需更宽的阅读区域，可用 DSH 的「收起侧边栏」按钮。
4. 在 DSH 配置好默认模型并确认登录或 API Key 可用。在聊笺的「工作台设置」中填写自己的微信称呼，即可识别「我的发言」。

**DSH Web**

```powershell
dsh plugin --profile web add "D:\下载\dsh-liaojian-0.1.0.tgz"
dsh web
```

## 每天怎么用

1. 在微信里多选要整理的消息，选择「转发 → 合并转发 → 转发到其他应用」。
2. 按以下任一方式把微信原始 ZIP 交给聊笺。
3. 在聊笺的「导入记录」查看排队和分析进度。完成后，按消息发生日期阅读日报，或切换到周报。

| 入口 | 操作 |
| --- | --- |
| **微信流投递到收件目录** | 打开聊笺「导入记录」，复制「微信流收件目录」。在微信流的「沉淀到文件夹」里选这个目录作为保存位置。微信流写入的 `微信流/附件/*.zip` 或直接保存到该目录的 ZIP 都能收到。微信流附带的归档笔记有会话名称时，聊笺会读取该名称。DSH 运行时每 10 秒检查一次收件目录。 |
| **工作台上传** | 点击「导入 ZIP」或将 ZIP 拖到工作台。支持多选。可以指定会话名称和群聊／私聊类型。同一会话的分批归档使用同一个名称即可合并。 |
| **直接发给 DSH** | 在微信流选择「发给 DeepSeek Harness」，等 ZIP 附件上传完成后，将会话输入改为 `/liaojian` 或 `/liaojian 会话名称` 并发送。在聊笺的「导入记录」中查看结果。也可以在微信流创建一个内容为 `/liaojian` 的投递场景，自动填入这条命令。 |

## 工作台

- **简报**按天和自然周回看。总览显示消息量、会话数、精选观察和我的发言，并列出重点和后续行动。支持立即汇总及导出带原话出处的 Markdown 简报。
- **分类列表**包含「全部观察」「与我有关」「学习」「内容选题」「机会」「我的发言」。可以按群聊、私聊和处理状态筛选，也可以跨日期搜索话题、会话或人物。
- **观察详情**显示摘要、关注理由、建议下一步和原消息。点击「查看上下文」可跳转到原会话的对应位置，也可以下载原始 ZIP。
- **跟进清单**收集尚未处理的待办和商机。收藏和已处理标记会保存在本地。可以在「所有会话」中编辑会话名称及类型。
- **定时汇总**默认使用北京时间。日报在每天 08:30 汇总前一天，周报在周一 09:00 汇总上一自然周。设置中可更改时间、时区、分类和参与分析的会话。关掉 DSH 后，定时任务暂停，重新打开会检查最近一期。历史日期可随时手动汇总。

## 格式和数据

- 接收微信原生合并转发的 ZIP，单文件上限 100 MB，聊天文本上限 8 MB。微信流分批投递的 ZIP 可以逐个导入。解析使用原生 `聊天记录.txt` 中的发送人、时间和正文。
- 图片、视频和其他附件保存在原始 ZIP 中。模型分析聊天文字及其中的附件描述。会话类型缺失时显示「未标注」，可在会话详情中补充。
- 消息、标记和简报保存在 `$DSH_HOME/liaojian/workbench.sqlite`，原始 ZIP 在同目录的 `archives` 下。微信流收件目录是 `$DSH_HOME/liaojian/inbox`。工作台只接收手动选择、上传或投递的归档。需要模型分析的文字会发送到 DSH 所配置的模型服务。
- 模型或网络出错时，已解析的原话仍可在「所有会话」中查看。修复模型设置后，在「导入记录」点「重新分析」即可。相同 ZIP 会按内容去重，同一会话中重叠的批次会按消息去重。

## 从源码打包

开发命令需要 Node.js 24.9 或更新版本。在项目根目录运行下面的命令。

```powershell
npm ci
npm test
New-Item -ItemType Directory -Path dist -Force | Out-Null
npm pack --pack-destination dist
```

安装清单是 `package.json` 和 `cordis.patch.yml`。服务端在 DSH 中解析归档、调用模型并保存数据，界面通过 DSH 的 `main` 和 `sidebar.panellist` 插槽加载。安装和 ZIP 接口分别参考了 [DSH 插件打包文档](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/user/develop/basic/publish.zh.md) 和 [微信流开源实现](https://github.com/freestylefly/WeChatBridge)。
